### 2. The 6-Layer Intelligence Stack

Every flagship product engineered follows a unified, hardened **6-Layer Intelligence Stack**:

| Layer | Component Name | Function & Technical Implementation |
| :---: | :--- | :--- |
| **Layer 1** | **Reception Gateway** | FastAPI / Express entry point. Validates incoming requests, authenticates identity, and applies input guardrails. |
| **Layer 2** | **Agent Router** | Intelligence dispatcher. Dynamically routes queries between cloud LLMs (Gemini) or local offline inference (Ollama) based on user privacy config. |
| **Layer 3** | **Prompt & Skill Engine** | Injects domain-specific instructions, Pydantic target schemas, and narrative tone constraints via progressive disclosure. |
| **Layer 4** | **RAG 2.0 Pipeline** | Hybrid FAISS + BM25 search followed by Cross-Encoder re-ranking to inject high-signal historical or classical context. |
| **Layer 5** | **Stateful Memory** | Embedded SQLite / PostgreSQL storage that tracks previous insights and eliminates conversational amnesia. |
| **Layer 6** | **Consistency & Auditor Loop** | Evaluator-Optimizer feedback loop. Validates mathematical consistency and JSON schema compliance before delivery to UI. |

#### 🎬 Case Study 1: [WatchMatch](file:///C:/Users/singh/Desktop/Portfolio/Case_Study_WatchMatch.md)
* **Tagline:** Agentic Cinephile Scout & Conversational Movie Discovery Engine.
* **Live Application:** [https://watch-match-rho.vercel.app](https://watch-match-rho.vercel.app)
* **Problem Solved:** Streaming decision fatigue and "infinite scroll paralysis" where users spend 24 minutes browsing catalogs without deciding.
* **Core Innovation:**
  - Conversational natural language query parsing without rigid genre dropdowns.
  - **Radical Recommendation Transparency**: Every suggestion includes a quantified **Match Score %**, bulleted **"Why it fits your prompt"** rationale, and an explicit **"Possible Mismatch" advisory** calling out slow pacing or graphic content.
  - **4-Axis Cinematic Mood Scales**: Interactive 0–100 sliders measuring Darkness, Pacing, Mind-Bending complexity, and Emotional Depth.
  - **CineTaste Passport**: Synthesizes a persistent cinephile archetype with 5-dimension Taste DNA bars and signature tropes.
* **Tech Stack:** React 19, TypeScript, Tailwind CSS v4, Express.js, Google Gemini GenAI SDK (`gemini-2.5-flash`), Vite, LocalStorage persistence.
* **Results:** **95% reduction in selection time** (from 24 mins to ~72 seconds), **88% shortlist conversion**, **4.9/5.0 trust score**.

  - **Adaptive Assessment Delivery**: 63-variable multi-instrument battery paired with an NLP semantic parser that extracts latent career affinities from free-text reflections.
* **Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, Python (FastAPI), SQLite/PostgreSQL, 63-Variable Scoring Engine, NLP Semantic Parser.
